# Reprendre Nous deux avec Claude Code

Lis les consignes communes et le contexte ci-dessous avant de modifier le projet :

@AGENTS.md

Pour lancer, tester et publier : `docs/DEVELOPMENT.md`.
Pour toute modification visuelle : `design-system/GUIDE-IA-nous-deux.md` et `DESIGN-INTEGRATION.md`.

Tu travailles sur l'application existante d'Abdellah et Laura, pas sur un nouveau prototype. Les comptes GitHub/Supabase connectés peuvent appartenir à l'un ou à l'autre ; cela ne change ni le dépôt ni le projet cible. Vérifie les capacités effectives de tes outils : une connexion MCP dans une autre interface Claude ne garantit pas qu'elle existe dans cette session Claude Code.

Les documents donnent le contexte ; la demande courante donne la tâche. Ne lance pas automatiquement une migration d'hébergement, une réinitialisation, une nouvelle application ou toutes les idées historiques. Sans tâche précise, résume brièvement l'état et demande ce que la personne veut changer.
